# What memlapse needs to run, pinned by version and by hash.
#
#     pip install --require-hashes --requirement requirements.txt
#
# pip turns hash checking on by itself as soon as any line carries a hash, so
# the flag is there for the day this file has lost them: without it, a file
# with no hashes at all would install unchecked and look no different doing
# it.
#
# Every package is named, not only the three the code imports. Nothing
# resolves this file, so what those three need is pinned beside them and the
# whole set is verified rather than just the part that was asked for. A pin
# with a "via" line is one of those.
#
# Each pin carries the sha256 of every file the index publishes for that
# version, because which wheel pip picks depends on the Python version and
# the machine doing the installing. A platform not listed fails with a
# message about a missing hash rather than quietly installing something
# unverified.
#
# To move a version, edit the pin by hand and then bring the hashes with it:
#
#     python scripts/lock_hashes.py requirements.txt requirements-dev.txt requirements-build.txt
#
# That reads the digests the index reports and downloads nothing. It chooses
# no versions either, so anything a new version needs that is not already
# pinned here has to be added by hand. PySide6, its two halves and shiboken6
# are released together and have to move together.
